# Changelog

All notable changes to this project will be documented in this file.

## [1.4.0] - 2026-04-03

### Added
- Skill summary tooltips on skill pills (chat bar, history, Agents carousel, mascot details): summary → preview → full prompt when you have access.
- Web: tooltips render in a fixed overlay (portaled to the document) so hover does not shift carousel or chat layout.

### Changed
- Chat: skill strip stacks above the message list on web so tooltips are not covered by bubbles.
- Skills tab: skill preview cards stay tappable but no longer show a redundant tooltip over the faded prompt preview.

### Fixed
- Tooltip positioning inside scroll views on web (flow layout retained on iOS and Android where needed).

## [1.3.0] - 2026-02-11

### Added
- Pricing and subscription models.
- Custom mascot creation flow.
- Custom mascots now stay local to the user.
- UI improvements across the application.
